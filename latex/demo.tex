\begin{abstract}
This page is rendered live in your browser by \LaTeX.js, a \LaTeX{} to HTML5
translator written in JavaScript. It shows a small but complete document:
sections, lists, tables, figures, mathematics and footnotes.
\end{abstract}

\section{Introduction}

\LaTeX.js parses \LaTeX{} source and produces HTML together with a stylesheet
that mimics the default \LaTeX{} output. Unlike a math-only renderer such as
KaTeX or MathJax, it understands the document \emph{structure} as well:
sections, lists, tables, figures and cross references.

The idea is simple. You write ordinary \LaTeX{}, and the result is a normal
web page --- no \TeX{} installation, no build step on the server.

\subsection{What this document covers}

\section{Mathematics}

Inline mathematics sits in the flow of a sentence: for instance
$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$ is the familiar closed form. A numbered
equation is set on its own line and labelled on the right:

\begin{equation}
  \int_{0}^{1} x^{2} \, dx = \frac{1}{3}
\end{equation}

Several lines can be aligned on a common symbol:

\begin{align}
  (a + b)^{2} &= a^{2} + 2ab + b^{2} \\
  (a - b)^{2} &= a^{2} - 2ab + b^{2}
\end{align}

Subscripts and superscripts compose naturally, as in $a^{2} + b^{2} = c^{2}$,
and Greek letters such as $\alpha$, $\beta$ and $\gamma$ are available.

\section{Figures}

Images are included with \texttt{includegraphics} and floated with a caption.
The width can be given in any familiar unit:

\begin{figure}
  \centering
  \includegraphics[width=8cm]{/img/stars.png}
  \caption{A figure placed with its own caption.}
\end{figure}

\section{Typography}

The Computer Modern fonts are shipped with the renderer, so the output really
does look like a \LaTeX{} document rather than a web page pretending to be
one\footnote{This is a footnote. In print it would sit at the bottom of the
page; on the web it is collected at the end of the document.}. Ligatures,
spacing and the shape of the letters all come from the same typefaces \TeX{}
uses.

\section{Conclusion}

Everything on this page was produced from plain \LaTeX{} source, inside the
browser, with no server-side processing at all.
